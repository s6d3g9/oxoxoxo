## Технические детали / Technical Details

### Изменения в кодировке / Encoding Changes

Файлы проекта были изначально в кодировке UTF-16LE с CRLF окончаниями строк. Это было исправлено на UTF-8 для лучшей совместимости.

Project files were originally in UTF-16LE encoding with CRLF line endings. This was fixed to UTF-8 for better compatibility.

### GitHub Actions

Добавлен workflow для автоматической синхронизации, который:
- Запускается по расписанию (каждую полночь UTC)
- Может быть запущен вручную
- Автоматически коммитит изменения при наличии

Added workflow for automatic synchronization that:
- Runs on schedule (every midnight UTC)
- Can be triggered manually
- Automatically commits changes when present
